# What You Learn

1. Chunking divides knowledge into focused sections.
2. Embeddings convert text into vectors that represent meaning.
3. Qdrant stores vectors and performs similarity search.
4. Retrieval sends a question embedding to Qdrant and selects nearby text.
5. Augmentation adds the retrieved text to a model prompt.
6. Generation asks Gemini to answer using that context.

An embedding model, vector database, and language model are individual components.
RAG is the complete retrieval, augmentation, and generation workflow.
